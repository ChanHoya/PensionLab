# UI/UX 리팩토링 의사결정 기록 (Context Notes)

PensionLab 대시보드 화면을 5대 UI/UX 기준에 맞춰 개편하는 과정에서 내린 주요 디자인 및 기술적 의사결정 기록입니다.

## 1. 배경 글로우 제거 및 전문 금융 서피스 채택 (Hallmark)
- **결정 배경**: AI 양산형 템플릿의 대표적 특징인 보라색 네온 글로우 구체(`bgGlow1`, `bgGlow2`)와 마법 구슬(🔮) 이모지가 신뢰가 생명인 연금 자산 관리 서비스의 전문성을 떨어뜨림.
- **조치 방향**: 부유하는 네온 구체를 전면 제거하고, ETF Lens 테마의 깊이감 있는 단색 서피스(`--surface`, `--surface-2`)와 정교한 보더(`--border`)를 통해 신뢰도를 극대화함.

## 2. 사이드바 도구의 계층적 재분류 (Frontend Design)
- **결정 배경**: 기존 사이드바에 27개의 모달 호출 버튼이 한 번에 펼쳐져 있어 스크롤이 과도하게 길고 인지 부하가 심각함.
- **조치 방향**: 은퇴 플래닝의 주 흐름에 맞추어 [1단계: 은퇴 전 준비 진단], [2단계: 연금 수령 최적화], [3단계: 세금·건보료 절감], [4단계: 생애 리스크 방어]의 4대 카테고리로 정리하고 기본 접기/펼치기 아코디언을 도입함.

## 3. 웹 접근성(a11y) 기준 강화 (Web Design Guidelines)
- **결정 배경**: 상단 백업/복원 버튼 및 토글러의 터치 타깃 높이가 28~32px 수준으로 모바일 터치 시 오조작 가능성이 높음.
- **조치 방향**: 최소 클릭 높이를 40px 이상으로 확장하고 `:focus-visible` 고대비 포커스 링을 부여하여 키보드 탐색성을 완성함.

## 4. 시맨틱 토큰 정합성 확보 (UI-UX Pro Max)
- **결정 배경**: 인라인 스타일에 임의의 rgba 투명도 색상이 산재하여 라이트/다크 모드 간 일관성이 저해됨.
- **조치 방향**: 전역 CSS 변수로 토큰을 승격하고 표 및 카드에 일관된 명도 대비를 부여함.

## 5. 물리 기반 모션 인터랙션 주입 (Emil Design Eng)
- **결정 배경**: 버튼 클릭과 탭 전환 시 시각적 피드백이 정적이며 뻣뻣함.
- **조치 방향**: 클릭 시 미세한 스케일 축소(`active:scale-[0.98]`)와 부드러운 스프링 감쇠 효과를 적용하여 손끝에 감기는 조작감을 구현함.

## 6. 후보 A/B/C 통합 개편 방향 (Sprint 49)
- **후보 A (모바일 최적화 및 바텀시트)**: 모바일(390px~430px)에서 가로 오버플로우를 원천 차단하고, 팝업 모달을 화면 하단에서 떠오르는 바텀시트 UI로 재구성하여 한 손 조작성과 터치 타깃(44px)을 확보함.
- **후보 B (AI Advisor 금융 전문화)**: AI 어드바이저 페이지의 배경 보라색 구체(`bgGlow`)와 🔮 이모지 등 AI 클리셰를 걷어내고, 차분한 시맨틱 헤더와 전문 금융 리포트 시각 체계를 구현함.
- **후보 C (Onboarding 전환율 극대화)**: 온보딩 위저드에서 네온 글로우를 제거하고, 하드코딩된 그라디언트를 시맨틱 토큰으로 교체하며, 최종 단계 액션 버튼에 명확한 시각 위계와 쫀득한 물리 스프링 피드백을 부여함.

## 7. 국민연금 추납·반납 실익 역산기 부부 탭 분리 및 다각도 실익 분석 고도화 (Sprint 50)
- **결정 배경**: 과거 미납·경단 기간 추납과 반환일시금 반납은 본인뿐 아니라 배우자(경력단절 전업주부 등)에게도 핵심적인 연금 증액 수단입니다. 기존 모달은 1인 단일 파라미터로 고정되어 부부 각각의 상황을 비교하거나 가구 차원의 통합 시너지를 조망하기 어려웠습니다.
- **조치 방향**:
  1. 모달 상단에 [👤 본인] / [👥 배우자] / [📊 부부 합산 시너지] 3개 세부 탭을 제공하여 각각의 상태를 독립 조작하고 실시간으로 시각화합니다.
  2. 납부 원금 대비 연금 수령액 분포를 다각도로 제시합니다. 연령대별 누적 회수율, 기대수명별(75세~95세) 순수익 매트릭스, 원금 회수 마일스톤(50% 반액 회수, 100% 원금 회수 골든크로스, 200% 더블 달성)을 시각화합니다.
  3. 반납 파라미터(원금, 경과 년수, 복원 개월수)를 사용자가 직접 인터랙티브하게 조절할 수 있도록 보강하고, 추납+반납 결합 시너지 시나리오를 계산합니다.
